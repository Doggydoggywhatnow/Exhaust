# Exhaust 0.1.0: build spec

**Scope: everything in `README.md`.** Items marked *(later)* or *(optional)* are stubs: present in the interface where the README places them, clearly labeled, disabled, and documented as not yet working. Everything else must work.

Finish and commit each slice, with its tests passing and CI green on Linux, Windows and macOS, before starting the next. Each slice ends with a "done when" check.

## 1. Window, text and accessibility tree
SDL3 window; widget tree with Clay layout; HarfBuzz/FreeType text with font fallback and color emoji; bidi and grapheme handling; piece-table buffer with undo tree; cursor, selection, IME, clipboard, multiple cursors; accessibility tree through AccessKit; scalable text.
**Done when:** you can type, select, undo and redo multilingual text in a window, a screen reader reads it, and buffer tests pass.

## 2. Vaults and files
Open and remember vaults; vault switcher button; file explorer tree on real folders; create, rename, move, delete, sort; open many file types; excluded files; symbolic links; file watching; tabs, splits, pop-out windows; saving; `.exhaust` config folder; settings with `settings.ini` and unknown-key preservation.
**Done when:** you can open two vaults, edit and save notes in tabs, change a file outside Exhaust and see it update, and `tests/test_settings.c` passes.

## 3. Markdown and live preview
Own tokenizer with source ranges; all Markdown in the README (headings, lists, tasks, quotes, code, tables, footnotes, comments, highlight, callouts, HTML subset); live preview, source mode and reading mode; folding; find and replace; editing shortcuts; slash commands; spell check; word count; Vim mode.
**Done when:** a sample note of every element renders correctly in all three modes and tokenizer tests pass.

## 4. Index, links and search
SQLite index with FTS5 and migrations; wikilinks and Markdown links with suggestions; backlinks, unlinked mentions, outgoing links; aliases; tags; properties read with libyaml and edited as text; page preview; link-safe renames; search with all operators and saved queries; quick switcher; command palette; outline; bookmarks; random note; footnotes pane.
**Done when:** a vault of 5,000 notes indexes, searches in well under a second, survives a deleted `index.db`, and the index compatibility test passes.

## 5. Graph view
Force-directed graph with Barnes-Hut layout, local graph, filters, groups, force sliders, animation, keyboard list route.
**Done when:** the 5,000-note vault draws and responds smoothly, and every graph action works from the keyboard.

## 6. Canvas, bases and structure features
Canvas in the JSON Canvas format; bases with table, list, cards, kanban and map layouts, formulas and functions; daily notes; templates; unique note creator; note composer; slides; format converter; embeds (notes, headings, blocks, images, audio and video via lib-Peep and libmpv, PDFs via PDFium); math renderer; diagram renderer; import tools; audio recorder, command line and URI scheme as stubs.
**Done when:** a sample vault with a canvas, a base, embeds, math and diagrams displays correctly.

## 7. Settings, hotkeys, themes, workspace
Settings screen following `screenshots/settings.png`; every command bindable with conflict display; themes and style snippets as described in the README, with live reload, contrast warnings and unknown-key preservation; workspaces; file recovery snapshots; status bar; ribbon; high contrast; interface zoom.
**Done when:** switching themes and editing a theme file update the app live, and the theme and settings compatibility tests pass.

## 8. Plugins and optional features
Lua plugin API with permissions; web clipper, community directory, languages, sync, shared vaults and publish as labeled stubs.
**Done when:** a sample plugin adds a command and a pane, and cannot touch anything it did not declare.

## Release
Update the README (dependency licenses confirmed, UI decisions recorded), tag `v0.1.0` on `dev`, and open a pull request to `main`.
