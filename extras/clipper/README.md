# Exhaust web clipper (not built yet)

A small browser extension that saves the page you are reading into your vault. It runs in your own browser, never inside Exhaust, and is the only place JavaScript is allowed in this project (`AGENTS.md`).

**Status: a stub.** Nothing here runs yet. It is planned for a later release; Exhaust shows it in *Settings, Plugins* as *Web clipper*, disabled and labelled *(later)*. The extension will need no account and will make no request of its own: it hands the page text to Exhaust, which stores it as a Markdown note.
